# 🚀 Modern .NET Journey

> **A production-style portfolio project documenting my transition from the classic Microsoft .NET Framework stack to the modern .NET ecosystem.**

---

## About This Project

After spending 25+ years developing enterprise applications with Microsoft technologies—including C#, ASP.NET MVC, Web API, SQL Server, WCF, Entity Framework, and Azure—I'm refreshing my skills by learning the modern .NET development stack the way it's used today.

Rather than completing disconnected tutorials, this repository documents the design, development, architecture, and lessons learned while building a real-world application from the ground up.

Every commit represents another step in that journey.

---

# Development Philosophy

This project follows several guiding principles.

- Learn by building
- Understand before copying
- Keep commits small and meaningful
- Prefer clarity over cleverness
- Treat every lesson as production code
- Document architectural decisions
- Always understand generated code
- Use AI as an assistant—not as a replacement for understanding

---

# Learning Method

Every lesson follows the same structure.

- Why this matters
- .NET Framework comparison
- Modern implementation
- Hands-on exercise
- Architecture discussion
- Best practices
- Keyboard shortcuts
- GitHub Copilot tips
- Common mistakes
- Interview questions
- End-of-lesson review
